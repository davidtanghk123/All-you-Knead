# All-you-Knead
All your Kneads in one place
# Purpose
Home baking has a few recurring problems:

1. **Recipes rarely fit what you need,** you often have to double and triple check what you need, and end up having to buy more anyways!
2. Scaling one loaf to three, or a 6-inch cake to a 12-inch one, **takes fiddly maths that's inconvenient to calcaulate if you are not buying more ingredients.**
3. **Following a recipe with messy hands is awkward.** Scrolling a long page covered in flour isn't fun.

# Core features
1. **Shared recipes with steps.** Recipes are stored with ingredients and ordered steps, and can be viewed two ways:
  1.1 Read-along: the full recipe on one page
  1.2 Swipe mode: one step at a time, with easy-to-reach controls
2. **Customize your recipies** Recepies can be duplicated from online copies, where you can change up certain ingredients
3. **Pantry tracker.** Keep track of household baking items like flour, eggs and butter.
4. **Scaling.** Scale a recipe by batch, and switch between amounts as item counts (3 eggs) or weight (150 g).

# Planned features
1. Comments and ratings on recipes, with photos
2. Ingredient prices from Singapore stores (e.g. NTUC FairPrice, Redman), with links to buy
3. Cake pan scaling (By size)



# Objectives

**This is a personal learning project. Beyond building a useful app, I'm using it to practise:**

**1. Backend and databases**
Designing a relational schema properly: normalisation, constraints, and a shared ingredient list
Writing raw SQL before moving to an ORM
Transactions, indexes, query performance (EXPLAIN ANALYZE) and migrations
Designing and building my own REST API with proper status codes, validation, pagination and testing


**2. Infrastructure**
Containerising every service with Docker and Docker Compose
Load balancing multiple API replicas behind Nginx
Building a separate authentication service with its own database
Health checks, metrics and dashboards with Prometheus and Grafana


**3. Data**
Scraping websites responsibly: respecting terms of service, caching, and rate limiting
Matching scraped products to my own ingredient data


**4. UI and UX**
Applying design fundamentals: visual hierarchy, button placement, colour theory and guiding users
Exploring interesting UI patterns and using Lottie animations with purpose
